WorkBuddy + OpenAI API — v2.1.1
================================

简体中文：先看 README.zh-CN.md。
想请 AI 帮忙：把解压后的源码文件夹交给助手，说「按 AI-SETUP.zh-CN.md 帮我配置」。
不要把私有 .env 文件发给助手。OpenAI API Key 和本机令牌都只在自己的电脑上填写，
不要粘贴到聊天。真实 API 验收会产生用量，先确认模型和请求数。

只想看思考区效果？运行 node oa-gateway.js --probe-summary。
探针固定用 127.0.0.1:8789，不读取密钥，不请求 OpenAI。具体设置见 README。

English: Start with README.md. For assisted setup, give your assistant the extracted
source folder and say "Help me configure this following AI-SETUP.md."
Do not share private env files or paste either credential into chat. Enter them locally.
Live tests use your API quota; approve the models and request count first.

To try the UI without a key, run node oa-gateway.js --probe-summary.
The probe listens on 127.0.0.1:8789 and makes no upstream requests. See README for setup.

Requires Node.js 22+. No npm install is needed. MIT; unofficial.
